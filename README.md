# Sled Dogs AI Sandbox

A standalone Unity project for designing and later testing expressive sled dog behavior. The current milestone is the development workflow; no dog behavior is implemented.

Open `Assets/_Game/Sandbox/Sandbox.unity` to view the flat test space.
