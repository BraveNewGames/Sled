# Dog behavior design

The goal is to make individual dogs feel like living creatures with recognizable traits, internal states, and relationships. This is a design goal from the planning conversation, not a set of approved mechanics.

For each spec, record decisions under **Approved**, ideas under **Proposed**, and unresolved choices under **Open questions**. Only Approved items are implementation requirements. Add examples and dependencies as decisions become concrete. Keep technical architecture in separate technical documents.

## Current state

No dog behavior rules have been approved for implementation. Discuss and approve a focused behavior before assigning a coding task.
