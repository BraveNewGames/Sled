# Personality and individuality

## Approved

None yet.

## Proposed

Explore stable traits that make individual dogs recognizable, such as confidence, curiosity, sociability, stubbornness, and responsiveness to commands.

## Open questions

- Which traits should be visible to the player?
- How should a trait change observable behavior without making every dog predictable?
- Which traits are stable, and which can develop?

## Dependencies

Emotions, social behavior, and autonomous behavior.
